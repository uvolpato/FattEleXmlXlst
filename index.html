FattEleXmlXlst
Prototipo

Convertitore XML Fatturazione Elettronica → Excel

Web app per caricare fatture elettroniche XML (FatturaPA 1.2), gestirle in elenco ed esportare i dati in un file Excel a 24 colonne.

Next.js + TypeScript Storage filesystem FatturaPA 1.2 / FPR12 24 colonne Excel
