FattEleXmlXlst
Prototipo

Convertitore XML Fatturazione Elettronica → Excel

Web app per caricare fatture elettroniche XML (FatturaPA 1.2), gestirle in elenco ed esportare i dati in un file Excel a 24 colonne.

Next.js + TypeScript Storage filesystem FatturaPA 1.2 / FPR12 24 colonne Excel
Accesso rapido
Prototipo interattivo
Apri il prototipo funzionante: upload drag-drop, elenco file, classificazione automatica, export Excel, visualizzatore XML.
Gestione utenti (admin)
Pagina admin per creare, resettare e eliminare utenti. Super user non eliminabile.
Documentazione
Specifica tecnica
Modello dati, parsing XML, classificazione file, mapping Excel 24 colonne, architettura API, stack tecnologico.
Preventivo
Attività svolte e da svolgere, tariffe orarie, riepilogo economico e confronto con sviluppo tradizionale.
Setup e installazione
Prerequisiti, installazione, configurazione, avvio sviluppo e produzione, risoluzione problemi.
